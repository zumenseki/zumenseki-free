# AGENTS.md — この知識ベース（脳）の歩き方

このフォルダ `brain-vault/` は所有者の「第二の脳」です。Obsidian で人間が閲覧・編集し、
Codex / Claude Code などのコーディングエージェントが**共有メモリ**として読み書きします。
複数プロジェクト（入札エージェント / ズメンセキ 等）の構想・仕様・決定を蓄積します。

容量は無限に増える前提です。だから **全文走査は禁止**。「地図 → 必要な1枚」だけ取りに行きます。

---

## 検索ルーティング（質問の種類で経路を変える）

研究の結論は「単一の万能構造は無い。質問の種類でルートを分ける」。だから2経路を使い分ける。

### 経路A：具体的な事実を1点引く（単一ホップ）
1. `00_INDEX/INDEX.md`（自動生成のカード目録）を **キーワード検索** する。
   → 固有名詞・用語での文字列一致が最速で堅牢（BM25的検索）。
2. ヒットした `path` の **葉ノートだけ** を開く。
3. 各ノート冒頭の `> 要約:` 行で要否を最終判断してから本文を読む。

### 経路B：横断的・多段推論・テーマ俯瞰（sensemaking）
1. まず `00_INDEX/HOME.md` を読む。
2. 該当する `00_INDEX/MOC_*.md`（要約ハブ）を **1枚だけ** 読む。
3. MOC内のリンク要約から、必要な原子ノートだけ降りて開く。

### 共通の禁止事項（コンテキスト節約）
- **本文の全件読み・`20_Notes/` の一括読み込みはしない。** 検索は INDEX / frontmatter /
  `> 要約:` 行に対してのみ行い、ヒットした葉だけを本文まで読む。
- INDEX に載っていない情報は「まだ存在しない」と判断してよい。
- 新規ノートを作ったら **必ず `node _tools/build-index.mjs` を実行して INDEX を再生成** する。

> なぜ: ノートが数万枚に育っても、1タスクで読むのは「INDEX 1枚 ＋ 該当の葉 数枚」に収束する。
> 構造化インデックスの主効果はトークン・レイテンシの大幅削減（≒検索速度そのもの）。

## 書き込みルール

- **1ノート = 1概念**。長くなったら分割し、リンク `[[ノート名]]` で繋ぐ。
- 新規ノートは必ずテンプレ（`_templates/` 参照）に従い、frontmatter と `> 要約:` 3行を付ける。
- 作業の結論・判断は、該当プロジェクトの `決定ログ.md` に **追記**する（既存行は消さない）。
- 新しい原子ノートを作ったら、対応する `00_INDEX/MOC_*.md` に**リンクを1行追記**する
  （MOC に載らないノートは他のエージェントから見えない＝存在しないのと同じ）。
- 不要になったノートは削除せず `90_Archive/` へ移動する。
- **ノートを追加・改名・移動したら `node _tools/build-index.mjs` を実行**して `00_INDEX/INDEX.md` を再生成する。

## frontmatter 規約（全ノート共通）

```yaml
---
type: project        # project | concept | log | resource | moc
project: ズメンセキ   # 関連プロジェクト名（無ければ省略可）
status: active        # active | paused | archived
tags: [面積測定, freemium]
aliases: [図面測定]    # 表記ゆれ・別名（検索ヒット率を上げる）
keywords: [PDF, canvas, Shoelace]  # 固有名詞・検索語（INDEXに載りgrep対象になる）
updated: 2026-06-17
---
```

`aliases` と `keywords` は INDEX の「キーワード」列に展開され、経路Aのキーワード検索の的になる。
固有名詞・略称・英日表記ゆれをここに入れておくほど、エージェントが本文を読まずに到達できる。

本文の最初の行は必ず引用ブロックの要約にする：

```markdown
> 要約: ここに1〜3行で「このノートは何か」を書く。エージェントはまずここだけ読む。
```

## フォルダの意味

| フォルダ | 用途 |
|---|---|
| `00_INDEX/` | 地図層。`INDEX.md`（自動生成カード目録＝検索の起点）/ `HOME.md` / `MOC_*.md`。 |
| `_tools/` | `build-index.mjs`（INDEX再生成スクリプト）。ノート追加・編集後に実行する。 |
| `10_Projects/` | 進行中の具体プロジェクト。各フォルダに `_overview.md` と `決定ログ.md`。 |
| `20_Notes/` | 原子ノート（1概念1ファイル）。MOC から参照される。 |
| `30_Resources/` | 参考資料・外部クリップ。 |
| `90_Archive/` | 終わった/不要になったもの。消さず退避（無限容量の受け皿）。 |
| `_templates/` | ノート作成用テンプレート。 |
