# 入札エージェント — Overview

## 何を解決したいか
- 入札案件の発見・選別・分析を自動化し、落札可能性と適正価格の判断を支援する。

## 想定する機能（ドラフト）
1. 入札情報の収集（公示・ポータルからの取得）
2. 案件の選別（条件・地域・規模でフィルタ）
3. 落札予測（過去データからの価格・勝率推定）
4. 関連資料の整理（図面→数量拾いは [[MOC_ズメンセキ]] と連携余地あり）

## 未決事項（要検討）
- 情報ソースと取得方法（API / スクレイピング / 手動）
- 予測モデルの種類とデータ入手
- どこまで自動化し、どこを人間の判断に残すか
